## 中文短总结

课程演示在当前界面中切换模型，并分别调整 reasoning effort 和 Fast Mode。模型、可选等级和用量限制取决于版本及账户；执行高成本任务前应检查当前设置。

## 中文长总结

- **切换模型：**演示中点击当前模型即可选择其他可用模型，无须重启项目；其他型号可能位于额外的模型菜单。
- **模型与 effort 是不同设置：**前者选择使用的模型，后者调整分配给任务的推理力度，在响应速度与推理深度之间进行权衡。
- **Fast Mode 与额度：**可在支持时切换快速模式；部分模型或功能可能受账户、组织设置或使用额度限制。
- **实践习惯：**随着任务难度变化调整设置，并在长任务开始前查看模型、effort 和用量提示。界面位置、型号及可用选项可能随版本改变。

## English Short Summary

The demonstration switches models within the current session and adjusts reasoning effort separately. Fast Mode and additional models may be available depending on the interface and account. Check the selected model, effort, and usage limits before demanding work.
