## 中文短总结

Claude 是模型系列，Claude Code 则是让模型在开发环境中使用工具的 AI coding agent。它不仅生成代码，还能根据权限检查项目、修改文件、运行命令并协助验证结果；开发者仍负责目标、授权和审查。

## 中文长总结

- **模型与工具的区别：**Claude 提供理解和推理能力；Claude Code 将模型接入项目及其开发工具，支持在终端、IDE 等环境中工作。
- **从回答到执行：**传统聊天通常需要手动复制代码、应用建议并测试；agent 可以直接搜索代码库、读取相关文件、跨文件修改并运行命令。
- **适用范围：**既可完成小型改动，也可协助理解陌生项目、定位缺陷、实现功能、重构、编写测试和维护代码。
- **责任边界：**任务越大，越需要明确上下文、规划、权限、测试和人工检查。模型产生的修改不应未经验证直接接受。

## English Short Summary

Claude is the model family; Claude Code is an agentic development tool that lets a model inspect and change a project and use tools within granted permissions. Developers still set goals, control access, review changes, and verify results.
