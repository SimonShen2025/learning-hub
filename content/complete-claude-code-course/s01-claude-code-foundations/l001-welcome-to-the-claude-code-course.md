## 中文短总结

课程围绕 Claude Code 在真实项目中的工程流程展开，从模型选择和安装，到上下文管理、代码修改、测试、权限与工具扩展，而不只是介绍孤立命令。

## 中文长总结

- **基础与设置：**理解 AI coding agent 与传统聊天的区别，认识模型选择的权衡，完成安装和基本配置。
- **项目工作流：**先了解现有代码和需求，再规划、实现、检查修改并运行测试；应用场景包括修复、重构、文档和 Git。
- **上下文与扩展：**通过项目指令管理持久上下文，并逐步学习权限、Skills、Subagents、MCP、Hooks 和 Plugins。
- **持续变化：**模型、命令和集成会更新，应结合当前工具版本和官方文档学习。

## English Short Summary

The course introduces Claude Code through real project workflows: choosing models, setup, context, planning, implementation, review, testing, permissions, and extensions such as skills and MCP. Features and interfaces can change over time.
