## 中文短总结

Desktop、终端和 IDE 是互补的工作界面：前者便于可视化管理，CLI 适合自动化，IDE 则方便结合当前代码与编辑器完成日常开发。

## 中文长总结

- Desktop 适合查看会话、diff 和预览，尤其适合需要可视化跟进多个任务时。
- CLI 能结合参数、管道、脚本和非交互执行，更容易接入自动化与 CI。
- IDE 方便引用打开的文件或选中的代码，并在编辑器旁审查修改。
- 不必固定使用一种界面；例如在 IDE 编程时仍可通过集成终端使用 CLI。具体入口和能力以当前版本为准。

## English Short Summary

Desktop, terminal, and IDE integrations serve complementary workflows: visual session management, scripting and automation, and close interaction with code in the editor. Choose the surface that fits the current task.
