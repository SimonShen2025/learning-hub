## 中文短总结

品牌规范描述产品身份，设计系统将其转化为可复用的颜色、排版、间距和组件规则，帮助新界面保持一致。

## 中文长总结

- 课程从已有 GitHub 项目提取颜色、字体、间距、圆角、阴影、组件与资源，建立可复用的视觉基础。
- 提取结果需要审查：旧颜色或实验性组件不一定代表当前标准，应明确每个 token 和组件的用途。
- 用一张新屏幕测试系统是否真正被应用，并检查颜色、排版、卡片、按钮和间距；只修复发现的不一致。
- 品牌文件、标志及其他授权素材可以补充产品身份；设计系统与品牌规范相关，但职责不同。

## English Short Summary

Brand guidelines express identity; a design system turns it into reusable visual tokens and components. Extract existing patterns, review outdated or experimental items, and test the system on a new screen.
