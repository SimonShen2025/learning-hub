## 中文短总结

课程介绍 Design、Slides、Design in Codebase 和 Design System 等入口，并以已有代码库为上下文创建首个移动首页，再通过简短反馈调整视觉优先级。

## 中文长总结

- 可从新设计、现有代码库或设计系统等不同起点工作；界面入口和功能需以当前账户为准。
- 使用已有仓库时，先确认相应集成和访问授权；现有组件与产品结构可为视觉探索提供上下文。
- 示例先生成驾驶应用首页，再突出开始行程、路线搜索和近期行程，观察主要操作是否易于识别。
- 先得到可讨论的初稿，再针对具体问题迭代，不必在第一条提示中定义完整产品。

## English Short Summary

Explore the Design workspace and start a visual project using an existing codebase as context. The lesson creates a mobile home screen, reviews the result, and iteratively clarifies the priority of its main actions.
