## 中文短总结

订阅、模型和 API 计费是不同概念：计划决定可用权限和额度，模型及任务会影响用量，API 通常单独计费。付费计划也有使用限制，应查看当前账户规则。

## 中文长总结

- **计划与模型：**课程介绍 Free、Pro 和不同 Max 档位；提高订阅额度不等于模型本身自动变得更强。价格、权益和可用模型可能变化，以账户及官方说明为准。
- **用量：**大型上下文、多次工具调用、更高推理力度和长任务可能消耗更多资源。课程演示了会话窗口和每周限制，以及不同 Claude 产品之间可能共享的用量。
- **达到限制后：**可等待重置，或在账户支持且明确同意额外费用时使用额外计费；启用前检查预算与支出上限。
- **API 区分：**Claude 订阅与 API 消费计费不是同一额度，不能假设订阅包含无限 API 调用。通过 Usage 和 Billing 页面核对实际限制与重置时间。

## English Short Summary

Subscription access, model selection, reasoning effort, and API billing are separate concerns. Usage depends on the work performed and remains limited on paid plans. Check current account limits and any extra-usage charges before enabling them.
