## 中文短总结

首次任务的核心流程是选择环境和项目、先理解代码库、提出小目标、审查权限与修改，再运行或预览结果并迭代；课程以添加和调整深色模式开关为例。

## 中文长总结

1. 选择本地目录或已连接的云端仓库，确认当前项目和 Git 分支；课程示例使用云端仓库。
2. 先要求 Claude Code 解释项目，让它检查结构和相关文件，再提出具体的界面修改目标。
3. 观察文件读取、搜索、修改和命令执行；出现权限请求时先确认操作与任务相符。
4. 运行或预览应用，验证开关确实工作；根据实际结果提出小幅后续调整，再次检查效果。
5. 当前会话可保留前面的任务上下文，但仍需审查实际变更。示例没有自动提交代码或创建 pull request。

## English Short Summary

Choose the environment and repository, inspect the project, request a small change, review permissions and edits, then run or preview the result. Iterate on feedback and verify the actual behavior; the demonstration does not commit or open a pull request.
