## 中文短总结

课程使用 Claude 账户登录。已有账户可直接使用；新用户可按界面完成邮箱验证、条款确认和初始设置，并自主检查隐私与数据使用选项。

## 中文长总结

- 课程演示通过邮箱接收临时登录链接；界面也可能提供验证码或其他登录方式。链接失效、地址错误或遇到安全验证时，按页面提示处理。
- 创建账户时检查适用条款和年龄要求；营销通知与模型改进相关选项应分别阅读，不要把可选项当作必选项。
- 完成姓名、工作类型等初始设置后进入 Claude；这些个性化步骤不等同于获得特定 Claude Code 计划权限。
- 登录方式、隐私控制及界面可能变化，应以当前账户设置为准，且不要向他人泄露登录链接或验证码。

## English Short Summary

Use an existing Claude account or complete the current sign-up and verification flow. Review terms, optional communications, and data-use preferences separately; the exact onboarding and sign-in options may change.
