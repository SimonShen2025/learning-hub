## 中文短总结

本课演示安装 Claude desktop 应用并进入其中的 Code 区域，而不是安装终端 CLI。使用已有账户登录后，确认应用能启动并可访问相应功能。

## 中文长总结

- 从 Claude 官方网站获取适合当前操作系统的桌面安装程序，安装后使用已有 Claude 账户登录。
- 桌面应用包含常规 Claude、Cowork 和 Code 等不同工作区域；Code 面向开发会话及项目，实际功能取决于版本和账户权限。
- 安装完成的基本检查是应用可以打开、账户可登录且能够找到 Code 区域。终端和 IDE 的其他使用方式并未在本课中安装或配置。

## English Short Summary

The lesson installs the Claude desktop application, signs in with an existing account, and locates its Code area. This demonstrates desktop access, not installation of the separate terminal CLI.
