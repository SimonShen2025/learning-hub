## 中文短总结

桌面 Code 界面围绕会话、操作记录、输入区与项目环境展开。应留意权限模式、模型和 effort，以及上下文和账户用量；安全与浏览器设置不要随意放宽。

## 中文长总结

- **会话与操作记录：**侧栏用于创建和恢复会话；会话记录可展示文件读取、命令、工具结果和代码变更。开始工作前确认仓库、环境和分支。
- **输入与运行状态：**输入区附近可切换权限模式、模型和推理力度；用量面板可查看当前上下文以及计划用量。上下文窗口与账户额度不是同一个限制。
- **设置位置：**账户、隐私、Billing、Usage 和 Code 设置分别管理身份、数据、计费与开发行为；Skills、Connectors、Plugins 和 MCP 等扩展有各自入口。
- **权限与风险：**Plan、Accept Edits 等模式具有不同的操作边界，应阅读当前界面说明。绕过权限检查、浏览器站点访问和连接外部服务都会扩大风险，不要仅为方便而启用。
- 课程演示的菜单和功能会随客户端、账户和版本变化；无需记住每个控件，优先理解其职责。

## English Short Summary

The desktop Code interface organizes sessions, tool activity, project details, prompts, permissions, model settings, context, and usage. Review repository and branch information and understand security settings before expanding access.
