## 中文短总结

使用斜杠菜单发现当前环境的命令。重点区分 `/compact` 的上下文压缩与 `/clear` 的重新开始；快捷键因桌面应用、终端和版本不同，应以当前帮助菜单为准。

## 中文长总结

- **发现与状态：**在输入框输入 `/` 查找命令；课程介绍 `/help`、`/status`、`/usage` 和 `/context`，用于查看帮助、环境、用量和上下文。
- **会话管理：**`/compact` 尝试保留关键信息并压缩当前会话；`/clear` 开始空上下文，不应当作等价操作。`/rename` 和 `/resume` 可帮助识别与恢复会话。
- **桌面演示快捷键：**`Esc` 可中断当前响应；`Ctrl+N` 新建会话，`Ctrl+Tab` 切换会话；`Ctrl+Shift+D` 和 `Ctrl+Shift+P` 分别用于 diff 与预览面板。
- **输入辅助：**`@` 可用于引用文件。其他快捷键及命令在不同客户端可能不同，使用当前版本的快捷键参考和命令菜单核对。

## English Short Summary

Use the slash menu to discover available commands. The lesson distinguishes `/compact`, which summarizes ongoing context, from `/clear`, which starts fresh, and introduces session and desktop shortcuts. Check the current client because commands and shortcuts can differ.
