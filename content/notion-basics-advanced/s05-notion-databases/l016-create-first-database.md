## 中文短总结

从新页面创建空数据库，先确定要管理的信息，再添加相应 properties，例如文本、数字、状态、日期、人员和公式。公式可引用其他 properties；先建可用的基础结构，再迭代调整。

## 中文长总结

1. 新建 Notion 页面并选择 database，再创建空数据库和名称。先明确数据库要解决的问题，再决定需要哪些字段。
2. 添加属性类型：文本、多选、状态、日期、人员、数字和公式等。属性名称及选项可后续修改，不必首次配置就穷尽所有可能。
3. 创建记录并填写数据。公式属性可引用数据库已有属性进行计算；底部计算可对数字属性统计数量、平均值、中位数、最大值或总和等。
4. 建议先建立必要字段与少量记录，验证数据结构是否合适，再增加公式和属性。课程也演示了用 AI 辅助编写公式；复制公式后仍需检查结果和属性类型。

## English Short Summary

Create an empty database, define the information to track, and add matching properties such as text, status, date, person, number, and formula. Formulas can reference other properties. Start with a minimal schema and refine it as real usage reveals needs.
