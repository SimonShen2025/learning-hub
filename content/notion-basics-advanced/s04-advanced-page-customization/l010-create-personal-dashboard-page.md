## 中文短总结

从空白页创建个人 dashboard，用标题和列划分个人、工作、效率等区域，再添加子页面、链接和 callouts。Dashboard 可集中导航而不必移动原页面；逐步搭建并边做边练。

## 中文长总结

- 创建空白页面并设置名称、图标、封面和 full-width 布局；用标题建立分类，再通过列组织内容。
- 在分类下创建子页面，或将现有页面链接到 dashboard。链接页面可集中入口而保留原有位置，避免为导航而重复或搬动内容。
- 可加入 callouts、提醒清单和常用模板，并调整颜色、图标与布局。先搭建能解决实际问题的基础结构，再随着学习增加数据库和视图。
- 页面结构可按个人或工作场景定制；课程建议边观看边动手，练习能帮助记住块类型和操作方式。

## English Short Summary

Build a personal dashboard from a blank page using headings, columns, subpages, linked pages, callouts, and reminders. Link existing pages to centralize navigation without moving them. Start with a useful base and expand it as your workflow develops.
