## 中文短总结

用键盘快捷键和 slash commands 减少页面编辑中的菜单操作。常见操作包括加粗、斜体、新建页面、搜索、标题格式和评论；Mac 与 Windows 的修饰键不同，按平台使用对应组合键。

## 中文长总结

- 对已选文本可使用快捷键进行加粗、斜体等格式操作，也可先启用格式再输入内容。
- 使用 `Cmd/Ctrl + N` 快速新建页面、`Cmd/Ctrl + K` 搜索；Mac 通常使用 Command，Windows 使用 Control。具体快捷键以 Notion 当前平台提示为准。
- slash commands 可快速插入页面块或设置标题，例如 `/h1`、`/h2`；输入 `---` 可插入分隔线。Enter 后新行会恢复普通文本，避免标题样式意外延续。
- 评论也可通过快捷键快速添加。课程提供 Mac 与 Windows 的完整快捷键清单，建议将高频操作加入个人工作流，而不是强记所有组合键。

## English Short Summary

Use keyboard shortcuts and slash commands to reduce menu navigation. Common actions include text formatting, creating a page, searching, inserting headings, dividers, and comments. Modifier keys differ between Mac and Windows; learn the shortcuts you use frequently.
