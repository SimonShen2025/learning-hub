## 中文短总结

Filter 控制哪些记录显示，sort 控制记录顺序，group 按属性分组；多条规则可组合。它们只改变视图，不会改变数据库的底层记录。

## 中文长总结

- Filter 用于缩小可见记录范围，例如筛选尚未开始的项目，或筛选负责人为某人的任务。可添加多个条件，并按 AND/OR 逻辑组合。
- Sort 按日期、状态等属性排序；多重排序按优先级依次应用，先处理主排序，再在相同值中应用后续规则。
- Group 按状态、人员或其他属性将记录分区，便于检查各类工作。可与筛选、排序以及 board 等布局结合。
- 这些规则属于视图配置，原始数据保持不变。先明确想回答的问题，再组合规则，避免视图过度复杂或隐藏需要关注的记录。

## English Short Summary

Filters control which records appear, sorts control their order, and groups partition them by a property. Combine multiple rules to answer a specific workflow question. These settings change the view, not the underlying records.
