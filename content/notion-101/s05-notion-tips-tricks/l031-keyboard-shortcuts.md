## 中文短总结

快捷键和 Markdown 输入可加快常见编辑：`Ctrl/Cmd + P` 打开 Quick Find，`Ctrl/Cmd + D` 复制块，`[[` 链接页面，`@` 插入提及/日期；标题、列表和格式也可用 Markdown 快速创建。

## 中文长总结

- `/` 命令是快速插入块的通用入口；可输入颜色命令设置文字或背景颜色。
- `Ctrl/Cmd + P` 打开 Quick Find，`Ctrl/Cmd + D` 复制选中块；`[[` 可链接或新建页面，`@` 可提及人员、插入日期或创建页面。
- Markdown 输入支持 `#` 标题层级、`*` 斜体、`**` 粗体、反引号代码、`-` 列表和 checkbox 等常见格式。
- 修饰键依操作系统而不同；以 Notion 快捷键面板/当前官方清单为准。优先练习高频操作，不必一次记住所有快捷键。

## English Short Summary

Use slash commands and Markdown for fast formatting. Common shortcuts include `Ctrl/Cmd + P` for Quick Find, `Ctrl/Cmd + D` to duplicate blocks, `[[` for page links, and `@` for mentions or dates. Modifier keys vary by platform.
