## 中文短总结

Table 适合密集数据编辑，Board 适合按阶段流转，List 适合简单清单，Gallery 适合视觉内容，Calendar 适合日期安排，Timeline 适合项目周期。可为同一数据库保留多个视图。

## 中文长总结

- Table：适合大量属性、数字及直接编辑，例如收入或费用跟踪。
- Board：按类别/状态组织卡片并拖动改变属性，适用于 CRM、项目阶段和课程规划。
- List：轻量展示，适合简单笔记或资源清单；Gallery：突出图片等视觉内容，如食谱和设计灵感。
- Calendar：按日期安排事件、发布计划或任务；Timeline：展示项目起止时间和周期关系，适合规划工作进度。
- 同一数据库可创建多个视图，让团队成员按偏好的方式查看共享数据；选择视图应由数据属性和任务场景决定。

## English Short Summary

Use table for dense data and editing, board for stage-based workflows, list for simple collections, gallery for visual content, calendar for dated items, and timeline for project durations. Multiple views can present the same database for different needs.
