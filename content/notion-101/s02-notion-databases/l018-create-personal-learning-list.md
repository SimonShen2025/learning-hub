## 中文短总结

用数据库集中管理待学资源，属性包括状态、收藏、媒介类型、主题和 URL。通过过滤视图显示正在学习的项目，以已完成且收藏的资源构建 Gallery，并按主题分组。

## 中文长总结

- 创建 Learning List 数据库，记录资源名称、状态（Not started/Started/Finished）、Favorite checkbox、Medium、Category 和 URL。
- 建立 Currently Learning 视图，只显示已开始且未完成的资源；以 Filter 保持视图聚焦，而不删除其他记录。
- 建立 Favorites Gallery，只显示已完成并勾选 Favorite 的资源，作为复习和推荐清单。
- 可额外创建 Board view 并按 Category 分组，以主题维度浏览内容。属性和值应按个人学习领域调整，避免把示例分类当作固定结构。

## English Short Summary

Build a learning-resource database with status, favorite, medium, category, and URL properties. Filter one view for in-progress resources, use a gallery for finished favorites, and group a board by topic.
