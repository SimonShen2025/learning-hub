## 中文短总结

Super 可用图片 caption 链接创建可点击图片，也可通过 CSS snippet 调整页面标题、callout 等样式。代码片段应限定作用范围并先测试，避免影响整个站点或破坏响应式布局。

## 中文长总结

- 为图片添加 URL caption，可让图片在 Super 网站中成为指向目标地址的链接。
- Super 页面支持添加自定义 CSS snippet，例如隐藏不需要的页面标题/图标，或将 callout 样式化为按钮。
- 课程资源提供现成 snippet，可复制到页面代码区域；应用前确认目标页面和选择器，避免全站意外生效。
- 修改后检查桌面和移动端布局、键盘可访问性及链接行为；保留原始样式，出现问题时可以快速回退。

## English Short Summary

Use an image caption URL to create linked images, and add CSS snippets in Super to customize page titles or callouts. Scope styles carefully, test responsive layouts and link behavior, and keep a rollback path.
