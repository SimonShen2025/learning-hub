## 中文短总结

进阶块包括 Template Button、提醒、人员提及、数学公式和代码块。按钮可重复插入预设内容；提醒可通过 `@` 日期创建并触发通知，适合减少重复操作和遗漏。

## 中文长总结

- Template Button 可保存一组块并在点击时重复插入，适合每周习惯追踪或固定清单，避免手动重建。
- `@` 菜单可设置日期/提醒，提及工作区成员会触发通知；Breadcrumbs 显示页面层级路径。
- Equation block 支持数学表达式；Code block 支持多种语言和语法高亮，适合技术文档和代码片段。
- 这些块针对特定需求提供增强能力。先明确是否需要重复内容、提醒、数学表达或代码展示，再选择相应块。

## English Short Summary

Special blocks include template buttons, reminders, people mentions, breadcrumbs, equations, and code blocks. Buttons insert reusable content; @ commands create reminders or mentions. Use these blocks when their specific workflow benefit is needed.
