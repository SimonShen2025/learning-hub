## 中文短总结

在 Power Apps Studio 中选择控件并修改其颜色或文字等属性，可快速调整应用外观。Gallery 中的模板控件会重复用于多个记录，因此修改模板样式可能同步影响所有条目。

## 中文长总结

### 修改应用样式

- 保存应用后，选择目标控件并在属性面板中调整颜色、文本或其他外观属性。
- 对难以直接选择的元素，可从 Tree view 定位控件。
- 使用预览检查修改后的视觉效果。

### Gallery 的重复行为

Gallery 使用模板呈现多条记录。修改模板中的控件样式会应用到各个重复条目；更改前后应检查整个 Gallery，而不只看单条记录。

## English Short Summary

Select controls in Power Apps Studio and edit their visual properties, using Tree view when needed. A Gallery repeats its template for multiple records, so template changes can affect every displayed item.
