## 中文短总结

完成租户设置后，可通过 Microsoft 365 的 App Launcher 打开 SharePoint 和其他已许可应用。管理员中心用于管理用户、许可证和密码；SharePoint 首页则是继续课程操作的起点。

## 中文长总结

### 打开应用

- 在课程演示中完成域名和 Teams 等设置后，进入 Microsoft 365 首页。
- 使用左上角的 **App Launcher** 打开 SharePoint，也可从中访问已提供的 Outlook、Excel、PowerPoint 等应用。
- 确认进入 SharePoint 页面后，即可继续课程中的站点操作。

### 管理用户

- 管理员中心提供用户管理入口，可查看活动用户、添加用户、调整许可证或重置密码。
- 这些管理选项仅适用于拥有相应管理权限的账户；应按组织的管理角色控制访问。

## English Short Summary

After tenant setup, use the Microsoft 365 App Launcher to open SharePoint and other available apps. Administrators can manage users, licenses, and password resets in the admin center; the SharePoint home page is the starting point for the course exercises.
