## 中文短总结

创建 Microsoft 365 试用环境时，按页面填写联系人和组织信息、完成电话验证，并为租户选择可用名称。随后创建负责管理租户的管理员账户；无需自有域名时可先使用 Microsoft 提供的默认域名。

## 中文长总结

### 注册与验证

- 使用邮箱启动注册，填写个人及组织信息，并按页面要求完成电话验证。
- 电话验证和试用资格等要求由 Microsoft 当前注册流程决定。

### 设置租户

- 为组织选择一个可用的租户名称；课程演示中使用 Microsoft 提供的 `onmicrosoft.com` 默认域名，而不是购买或连接自有域名。
- 创建租户管理员账户，用于管理组织中的 SharePoint 和其他 Microsoft 365 服务。
- 如有自有域名，课程指出之后可以连接该域名；它不是跟随演示开始使用默认租户地址的前提。

注册界面和试用条件可能更新，实际操作时以 Microsoft 当前流程为准。

## English Short Summary

The walkthrough creates a Microsoft 365 tenant by entering registration details, completing phone verification, choosing an available organization name, and creating an administrator account. A custom domain is optional for the demonstration, which uses Microsoft's default onmicrosoft.com domain.
