## 中文短总结

课程使用 Microsoft 365 E3 试用环境演示 SharePoint Online，方便没有现有租户的学员跟做。讲师提到其演示试用包含多个用户许可证并有期限；具体试用资格和条款应以 Microsoft 当前页面为准。

## 中文长总结

### 演示环境

- 如果已有可用的 SharePoint 环境，可以沿用现有环境；否则可按课程演示创建一个 Microsoft 365 环境。
- 讲师以 Microsoft 365 E3 试用为例，其中包含 SharePoint Online 以及 Word、Excel、PowerPoint、Outlook 等在线应用。
- 课程演示提到试用期和许可证数量，但这些条款可能变化；实际创建前应核对 Microsoft 当前提供的资格、期限和限制。

### 学习建议

在自己的环境中跟随课程操作，有助于将演示步骤转化为实际操作经验。

## English Short Summary

The course demonstrates SharePoint Online using a Microsoft 365 E3 trial environment for learners who do not already have a tenant. Trial availability, duration, and license limits can change, so check Microsoft's current terms before signing up.
