## 中文短总结

Classic SharePoint 的站点设置包含搜索配置，例如结果来源、结果类型、查询规则、Schema 和搜索垂直分类。它们影响搜索范围与呈现；更改前需了解租户配置、权限和影响范围。

## 中文长总结

### 搜索配置概览

课程在 Classic Site settings 中介绍了多种搜索设置：

- **Result sources**：定义可搜索的来源。
- **Result types**：控制不同类型结果的呈现。
- **Query rules**：根据查询配置相关结果或规则。
- **Search schema**：管理可搜索的属性。
- **Search settings / verticals**：配置不同搜索分类及其范围。

### 管理注意事项

这些设置较为高级，常规用户通常不需要调整。修改可能影响搜索结果的范围、显示或可发现性；应遵循管理员流程，在充分了解后于目标环境中验证。Modern 与 Classic 搜索选项可能不同。

## English Short Summary

Classic Site settings expose search configuration such as result sources, result types, query rules, schema, and search verticals. These can affect what users find and how results appear; change them only with appropriate administrative understanding and testing.
