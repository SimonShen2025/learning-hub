## 中文短总结

除从 Excel 创建外，还可新建空白 List、从现有 List 复制结构，或使用带预设列和视图的模板。复制现有列表通常只复制结构、不复制记录；模板内容与工作流取决于具体模板。

## 中文长总结

### 创建方式

- **Blank list**：从空白列表开始，再逐步添加列和记录。
- **From existing list**：复用已有列表的结构；课程演示中仅复制列等结构，不复制现有项目。
- **Templates**：使用带预设列、视图或流程的列表模板，例如招聘跟踪器。

### 选择方式

已有 Excel 数据可从工作簿导入；要自定义结构可从空白列表开始；若目标结构相近，可复用现有列表或模板。创建后仍应检查列类型、视图和相关设置是否符合实际需求。

## English Short Summary

Create a blank List, copy the structure of an existing List, or start from a template with predefined columns and views. The demonstrated existing-list option copies the structure but not the records; template features vary.
