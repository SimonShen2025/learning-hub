## 中文短总结

List 的 New/Edit 表单可通过 Edit form > Edit columns 调整字段顺序或隐藏字段，让表单更符合录入流程。隐藏字段只影响表单显示；若要阻止用户访问或修改数据，应使用权限和适当的数据设计。

## 中文长总结

### 调整表单

- 在 List 的新增或编辑表单中打开 **Edit form > Edit columns**。
- 选择要显示的列，并调整顺序；保存后，新表单会按设置呈现字段。
- 可按实际录入流程安排字段，减少用户面对不相关字段的负担。

### 显示与权限的区别

从表单中隐藏字段只是界面调整，不应作为保护数据或限制修改的安全措施。需要控制用户可查看或编辑的数据时，应配置合适的访问权限。

## English Short Summary

Use Edit form > Edit columns to reorder or hide fields in a List's New/Edit form. This changes the form experience only; use permissions and appropriate data design to control access or prevent edits.
