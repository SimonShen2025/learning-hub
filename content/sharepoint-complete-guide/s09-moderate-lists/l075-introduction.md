## 中文短总结

SharePoint Lists 用行和列管理结构化数据；Document Library 则是面向文件的列表，每行对应一个文档。Lists 适合联系人、销售或交易等记录，不要求每条数据都附带文件。

## 中文长总结

### Lists 与 Document Libraries

- SharePoint List 以行和列保存记录，可用于联系人、销售、交易、课程等结构化信息。
- Document Library 在列表式界面中管理文件，每条记录对应一个存储的文件。
- List 项目可按需要添加附件，但附件不是每条记录的必需内容。

### 共通能力

Lists 与文档库在版本历史、视图及部分管理方式上有相似之处。后续内容将介绍如何创建、编辑和管理 List 数据。

## English Short Summary

SharePoint Lists store structured records in rows and columns, such as contacts or transactions. A Document Library is a file-focused list in which each row represents a stored document; ordinary list items do not require an attachment.
