## 中文短总结

从 Excel Table 创建 List 时，选择要导入的表并为每列指定合适的数据类型，再设置列表名称和描述。默认 Title 列应按数据用途合理映射；导入后可继续调整列设置。

## 中文长总结

### 导入流程

- 在创建列表时选择 **From Excel**，上传工作簿并选择要导入的 Table。
- 查看数据预览，为每列指定类型，例如文本、日期或 Choice。
- 设置列表名称和描述，并决定是否将其加入站点导航。

### 设计 Title 列

导入时需考虑默认 **Title** 列应表达什么信息。课程示例选择 Email 作为联系记录的标题字段；不同数据集可以选择名称、编号或其他易识别的值。Title 不是自动生成的唯一键，若业务要求唯一性，应另行设计和验证。

## English Short Summary

When creating a List from Excel, upload the workbook, select the intended Table, map each column to an appropriate data type, and set the list name and description. Choose a useful value for the default Title field; it is not automatically a unique key.
