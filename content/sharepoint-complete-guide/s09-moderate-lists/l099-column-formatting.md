## 中文短总结

Column formatting 可根据字段值改变单元格的显示样式，例如为 Choice 值设置背景颜色、使用 choice pills，或配置条件格式。它影响该列的呈现，而不是整行或底层数据。

## 中文长总结

### 设置格式

- 从列菜单打开 **Column settings > Format this column**。
- 可使用背景颜色、Choice pills 或条件格式等样式，并按需要调整颜色。
- 格式可以帮助用户快速区分 Choice 值或突出符合条件的数据。

### 呈现边界

Column formatting 控制当前列的视觉呈现，不会修改字段值，也不等同于整行格式。若需要影响更大范围的显示，应使用适合该场景的视图或格式设置。

## English Short Summary

Format a column with value-based background colors, Choice pills, or conditional formatting to make List values easier to scan. Column formatting changes how that column appears, not the underlying data or the entire row.
