## 中文短总结

List 项目可通过单项编辑表单、批量选择或 Edit in grid view 修改；网格视图也支持从 Excel 复制粘贴多行数据。导入列表的表单若未显示所有列，课程演示了通过内容类型设置调整可编辑字段。

## 中文长总结

### 编辑方式

- 打开单条记录的编辑表单，更新字段、附件或评论。
- 选择多条记录进行批量操作。
- 使用 **Edit in grid view** 以表格方式编辑多行，也可复制粘贴数据。

### 内容类型与表单字段

课程演示中，Excel 导入后的编辑表单未显示所有列。讲师通过 List settings 启用内容类型管理，再将现有列加入 Item 内容类型，以便在表单中编辑这些字段。该设置路径可能因界面和列表类型而异；修改前应确认目标列及当前列表配置。

## English Short Summary

Edit List items individually, select multiple records for bulk changes, or use Edit in grid view to update rows and paste data from Excel. If imported-list columns are missing from the form, the course demonstrates exposing them through content-type settings; the exact path may vary.
