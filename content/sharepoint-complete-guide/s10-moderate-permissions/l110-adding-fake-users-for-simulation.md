## 中文短总结

课程使用 Microsoft 365 管理中心创建测试用户，以模拟真实组织中的 SharePoint 成员。此步骤需要相应的管理员权限；应在授权的测试租户中操作，并仅分配测试所需的账号和许可证。

## 中文长总结

### 准备测试账号

- 课程从 Microsoft 365 管理中心的 Active users 页面添加测试用户。
- 创建账号时需配置用户名、登录信息及适用的许可证，之后可用这些账号验证不同权限。
- 若组织已有经批准的测试账号，可直接使用，不必重复创建。

### 安全注意

创建用户和分配许可证需要管理员授权。优先使用隔离的测试租户和虚构身份；不要在生产组织中擅自创建账户、转发密码或分配不必要的许可证。按组织的账号生命周期与凭据管理流程执行。

## English Short Summary

The course creates test users in the Microsoft 365 admin center to simulate site members. Use an authorized test tenant, obtain the required admin approval, and assign only the accounts and licenses needed for testing.
