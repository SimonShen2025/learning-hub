## 中文短总结

Authentication 验证用户身份，Permissions 决定该用户可以在 SharePoint 中查看、创建、编辑或删除什么。权限设计需在易管理与最小必要访问之间取得平衡，避免权限过度分散或授予过宽。

## 中文长总结

### 身份验证与权限

- **Authentication** 确认用户是谁，SharePoint 登录由 Microsoft 365 身份体系处理。
- **Permissions** 决定已登录用户可访问的站点、内容和操作，例如读取文件或编辑 List。

### 权限平衡

逐个用户、逐个项目设置权限可很精细，但难以长期维护；广泛授予访问则会增加数据被误改或未经授权访问的风险。设计权限时应根据业务需求限制访问范围，同时保持结构可管理，并定期复核。

## English Short Summary

Authentication verifies a user's identity; SharePoint permissions determine which sites, content, and actions that user can access. Balance manageability with least-necessary access to reduce both administrative complexity and overexposure.
