## 中文短总结

可从父站点的 Site contents 进入 Sites 并创建子站点，设置名称、地址和模板。创建时可继承父站点权限或配置独立权限，并选择是否将子站点加入父站点导航。

## 中文长总结

### 创建入口和属性

- 从父站点的 **Site contents > Sites** 创建子站点。
- 设置站点名称、URL 和模板；课程示例选择 Team Site，也展示了 Project Site 等模板。
- 子站点拥有自己的页面、文档库和 Site contents；区别在于它被创建为父站点层级中的一部分。

### 权限与导航

- 可选择继承父站点权限，或为子站点建立独立权限。
- 可决定是否显示在父站点的快速启动或顶部链接栏，并配置是否继承父站点导航。

模板和创建选项会随 SharePoint 环境变化；创建前应先确认目标权限和导航结构。

## English Short Summary

Create a subsite from the parent site's Site contents > Sites, then set its name, URL, and template. Choose whether it inherits parent permissions and whether it appears in the parent navigation.
