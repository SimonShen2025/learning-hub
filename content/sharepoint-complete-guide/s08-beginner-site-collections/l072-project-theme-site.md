## 中文短总结

课程演示的 Project Site 模板预置 Project Summary 和 Tasks 等项目组件，可用于查看任务和项目状态。它与通用 Team Site 的起始内容不同；模板及 Classic/Modern 体验取决于当前租户。

## 中文长总结

### Project Site 模板

- 从父站点创建子站点时选择 **Project Site** 模板。
- 模板可预置项目摘要和任务列表等组件，帮助团队记录任务、负责人和日期。
- Team Site 则更通用，团队可自行添加需要的应用和 Web Parts。

### 使用注意

课程演示中的 Project Site 使用 Classic 界面，且某些模板或组件可能不适用于所有 SharePoint 环境。创建前应确认模板可用性、权限配置及站点维护需求。

## English Short Summary

The course's Project Site template includes project-oriented components such as a summary and task list, unlike a general Team Site. Template availability and Classic or Modern behavior depend on the current SharePoint tenant.
