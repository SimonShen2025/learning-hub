## 中文短总结

从 SharePoint 起始页创建 Communication Site 时，可选择 Topic、Showcase 或 Blank 等设计模板，并设置名称与描述。Communication Site 使用不同于 Team Site 的页面布局和导航方式，适合发布面向受众的信息。

## 中文长总结

### 创建站点

- 从 SharePoint 起始页选择 **Create Site > Communication Site**。
- 根据内容和视觉需求选择设计模板，例如以信息发布为主的 Topic、强调展示的 Showcase，或 Blank。
- 设置站点名称和描述后完成创建。

### 与 Team Site 的初步区别

课程演示的 Communication Site 使用顶部导航和以内容展示为主的主页布局。后续课程会进一步比较其页面、默认应用和导航方式。

## English Short Summary

Create a Communication Site from the SharePoint start page, choose a design such as Topic, Showcase, or Blank, and set its name and description. Its navigation and content-focused layout differ from a Team Site.
