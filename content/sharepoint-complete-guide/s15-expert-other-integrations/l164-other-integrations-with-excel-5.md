## 中文短总结

Excel 中格式化为 Table 的数据可发布为新的 SharePoint List。课程示例演示 Excel 根据列内容识别文本、数字和日期；发布前应检查数据类型、列名和目标站点。

## 中文长总结

### 从 Excel 创建 List

- 在 Excel 中将数据整理为表格，并确保首行为清晰的列标题。
- 使用 **Export to SharePoint List**，填写站点根地址、List 名称和说明。
- 检查 Excel 识别的列类型，确认后创建 List，并核对发布后的记录和字段。

### 导入前检查

清理数据中的空值、重复记录和错误格式。发布会在 SharePoint 创建新 List；确认目标站点和访问范围，并验证类型转换后的结果符合预期。

## English Short Summary

Format Excel data as a table and use Export to SharePoint List to create a new List. Review the detected column types, destination, and imported records before relying on the published data.
