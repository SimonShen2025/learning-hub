## 中文短总结

在文档库添加 Choice 列，可用固定选项为文件记录部门等 metadata，并限制用户自行添加新值。已有文件可通过详情面板或 Edit in grid view 批量补齐；多个列可记录不同分类维度。

## 中文长总结

### 创建 Choice 列

- 从 **Add column** 选择 **Choice**，为列命名并输入允许的值，例如部门名称。
- 可配置单选或多选、下拉列表或单选按钮，并决定用户能否自行添加选项。
- 若希望值保持统一，应限制用户添加自定义值，由管理员维护选项列表。

### 填充现有文件

- 新增列后，旧文件可能缺少该列的值；如将列设为必填，需要为这些文件补齐信息。
- 可在文件详情/属性中编辑单个值，也可使用 **Edit in grid view** 像表格一样批量更新多行。
- 可按同样方式增加其他分类列，例如费用类型，让文件同时拥有多个 metadata 维度。

## English Short Summary

Add a Choice column to a document library to assign controlled metadata such as department. Configure allowed values and selection behavior, then fill existing items individually or in bulk using Edit in grid view. Additional columns can capture other categories.
