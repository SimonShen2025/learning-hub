## 中文短总结

可编辑站点导航，将新文档库或常用外部资源添加为链接，也可隐藏不常用入口，让用户更容易找到需要的应用。导航隐藏仅改变入口显示，不会替代文档库或站点的权限设置。

## 中文长总结

### 添加导航链接

- 编辑站点左侧导航，添加指向新文档库的链接并设置显示名称。
- 可调整导航项顺序，也可添加外部资源链接，方便用户访问常用门户或业务系统。
- 可移除不希望显示在导航中的默认入口，使菜单聚焦于目标应用。

### 导航与访问控制

导航主要用于发现和打开资源。隐藏链接或 Site contents 入口本身不会阻止用户通过其他方式访问资源；需要限制访问时，应另外配置站点或文档库权限。

## English Short Summary

Edit site navigation to add links to a new library or frequently used resources, reorder entries, and hide links that are not useful to the intended audience. Navigation controls discoverability, not access; configure permissions separately.
