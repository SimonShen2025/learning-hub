## 中文短总结

文档库工具栏提供共享、同步、下载和导出等操作。下载文件夹会打包文件但不保留 metadata；Export to Excel 可导出文件链接及列数据。视图可切换布局，也能使用 Filters 和 Info 面板。

## 中文长总结

### 文件操作

- 可共享整个文件夹或选定文件，并复制链接。
- 下载文件夹会将文件打包，但不会保留文档库的 metadata。
- **Export to Excel** 可导出文件链接、修改信息和其他列数据，适合需要连同 metadata 查看或处理的场景。

### 视图和面板

- 工具栏可切换列表、紧凑列表或 Gallery 等布局；选择布局时需考虑哪些列信息会被显示。
- **Filters pane** 用于访问筛选条件；**Info pane** 显示当前文件夹或文件的详情。

### 后续集成

课程后续会介绍以文档库为数据源的 Power Apps 和 Power Automate 场景。

## English Short Summary

The library toolbar provides sharing, sync, download, and export actions. Downloading a folder packages files but omits metadata; Export to Excel includes links and column data. Layout choices, the Filters pane, and the Info pane control how library content is viewed.
