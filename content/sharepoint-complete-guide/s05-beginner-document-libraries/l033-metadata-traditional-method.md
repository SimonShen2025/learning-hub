## 中文短总结

传统文件夹结构通常按单一维度组织文档；需要按部门、费用类型等多个维度查找时，文件会分散在不同位置，搜索也容易受命名不一致影响。Metadata 可为同一文件记录多个分类维度。

## 中文长总结

### 文件夹方式的局限

- 课程以费用收据为例，按部门创建文件夹后，可按部门浏览文件。
- 若要跨部门查找同一费用类型，文件分散在多个文件夹中，需要逐个定位。
- 目录结构通常让文件固定在某个位置；依赖文件名和手工分类，也容易出现拼写不一致，影响搜索。

### 为什么引入 Metadata

当用户需要从不同角度查看同一批文件时，只靠文件夹可能不够灵活。为文件添加部门、费用类别等 metadata，可以在同一文档库中支持多种分类和检索方式。文件夹仍有适用场景，后续课程将演示 metadata 如何补充或替代部分目录分类。

## English Short Summary

Folders organize files by a hierarchy, often around one category. Finding files across departments by expense type can require searching multiple locations, and inconsistent naming can hinder search. Metadata lets the same file carry multiple classification values.
