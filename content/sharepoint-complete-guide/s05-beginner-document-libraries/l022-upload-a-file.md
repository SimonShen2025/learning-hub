## 中文短总结

SharePoint 站点通常预置名为 Documents 的文档库，可将单个或多个文件上传到团队共享位置。文档库让组织成员能够集中访问文件，后续课程会继续介绍其管理功能。

## 中文长总结

### 上传文件

- 打开站点中的 **Documents** 文档库，使用 **Upload** 选择一个或多个文件。
- 文档库也支持上传文件夹或模板；本节演示批量选择并上传多个文件。

### 文档库的作用

文档库是站点中供团队共享和管理文件的应用。课程后续会介绍更多能力，例如文件属性、metadata、版本管理和访问控制；它的用途不只是存放文件。

## English Short Summary

SharePoint sites commonly include a Documents library for shared files. Use Upload to add one or multiple files; folders and templates can also be uploaded. Later lectures cover additional library features such as metadata and version history.
