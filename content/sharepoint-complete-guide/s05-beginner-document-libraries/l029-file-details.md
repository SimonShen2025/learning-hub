## 中文短总结

文件详情面板集中显示访问权限、属性、活动记录和文件信息，也可添加评论、复制路径或共享链接。路径用于说明文件在站点和文件夹中的位置；共享链接则直接指向文件。

## 中文长总结

### 详情面板

- 选择文件并打开 **Details**，可查看谁有访问权限、修改属性和 metadata，并查看文件活动记录。
- 活动记录可显示创建、重命名和修改等事件；评论可用于补充说明和讨论。
- 面板还可能显示文件类型、尺寸、时长等与文件相关的信息。

### 路径与链接

- **Copy path** 提供文件在站点、文档库和文件夹结构中的位置。
- **Copy link** 生成可共享的文件链接，实际访问仍取决于权限设置。

详情面板也适用于文件夹，可用于查看其访问权限。

## English Short Summary

The Details pane shows access, properties, metadata, activity, comments, and file-specific information. Copy path describes where a file sits in the site and folder structure; Copy link provides a direct shareable link, subject to permissions.
