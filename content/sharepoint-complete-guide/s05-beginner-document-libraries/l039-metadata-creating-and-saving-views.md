## 中文短总结

View 是同一底层文件数据的不同呈现方式，不会复制或改变数据。可保存个人或共享视图，并配置显示列、筛选、排序、分组和汇总，让不同角色看到适合自己的文档库内容。

## 中文长总结

### View 的作用

视图改变文件的呈现方式，而不是底层数据。例如，费用管理员可以只看高金额项目；会计人员可以只看会计部门文件。

### 创建和保存

- 调整筛选或分组后，可使用 **Save view as** 保存当前视图，并选择仅自己可见或供其他用户使用。
- **Edit current view** 可进行更细致的配置，例如选择列、设置排序和筛选、按 metadata 分组及设置总计。
- 组织可为不同角色建立多种视图；应仅共享对他人有用的视图，并确保筛选条件符合访问控制要求。

## English Short Summary

A view changes how the same underlying files are presented without changing or duplicating the data. Save personal or shared views with selected columns, filters, sorting, grouping, and totals so different roles can focus on relevant library content.
