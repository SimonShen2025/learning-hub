## 中文短总结

文档库中的 Office 文件可在浏览器中打开和协作编辑，也可共享给组织成员。文件属性、访问管理和版本历史可从文件操作菜单查看；metadata 列有助于按业务信息组织文件。

## 中文长总结

### 打开和编辑

- 打开 Word、Excel 或 PowerPoint 文件后，可在浏览器中编辑；Office 文件支持自动保存及多人协作编辑。
- 文件详情面板可显示预览和相关属性。

### 共享和管理

- 可向组织成员共享文件或复制链接；访问对象仍受组织和文件权限控制。
- 文件菜单可查看访问权限和版本历史，并执行下载、删除、移动等操作；多个文件也可批量处理。

### Metadata

文档库列可记录文件属性，metadata 可用于分类和查找，是课程后续重点讲解的组织方式。

## English Short Summary

Office files in a SharePoint library can be edited in the browser with autosave and co-authoring. Files can be shared with organization members, while details, access management, and version history are available from file actions. Metadata columns help organize files.
