## 中文短总结

数值或 Currency 列可把费用金额作为 metadata 保存，避免逐个打开收据查看。文档库可按金额排序，并通过总计显示 Sum、Average、Maximum、Minimum 或 Count；分组后也能查看各组汇总。

## 中文长总结

### 添加金额列

- 添加 Number 或 **Currency** 列，将金额作为文档库中的 metadata。
- 可设置显示格式、小数位和默认值；如果每个文件都必须填写金额，可将列设为必填。
- 现有文件可在文档库中补充金额，再通过列排序或筛选定位项目。

### 汇总

- 列总计可计算 Sum、Average、Maximum、Minimum、Count 等统计值。
- 与部门等 metadata 分组后，可同时查看每组的金额汇总和整体汇总。

将金额作为 metadata，可直接在文档库视图中比较和汇总文件，而无需打开每个文档读取数据。

## English Short Summary

Add a Number or Currency column to store expense amounts as metadata. Sort or filter the library by amount, and use column totals such as Sum, Average, Maximum, Minimum, or Count. Grouping by another field can show per-group and overall summaries.
