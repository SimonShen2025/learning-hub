## 中文短总结

文档库的 Library settings 集中管理名称、描述、导航、版本、必需 Check out、内容类型、验证、权限、工作流、列和视图等选项。部分设置位于 Classic 页面，功能和路径可能随 SharePoint 版本变化。

## 中文长总结

### 进入设置

从文档库右上角齿轮菜单打开 **Library settings**。课程演示中部分高级配置会进入 Classic 设置页面；日常列和视图操作通常也可在较新的界面完成。

### 常见配置类别

- **General settings**：更改库名称和描述，或将库加入快速启动导航。
- **Versioning settings**：配置版本类型、版本保留方式、审批和是否强制 Check out。
- **Advanced settings**：管理内容类型、模板和新建文件夹等行为。
- **Validation / default values**：定义输入约束或默认值。
- **Permissions and workflow**：管理库访问权限及相关工作流设置。
- **Columns and views**：添加或排序列，创建视图；部分高级视图选项也可从此处配置。

### 配置原则

设置会影响整个文档库中用户创建和编辑内容的方式。修改前应确认组织的权限、审批、版本保留和内容验证要求；具体选项以当前 SharePoint 界面为准。

## English Short Summary

Library settings manage the library name, navigation, versioning, required check-out, content types, validation, permissions, workflows, columns, and views. Some advanced options may appear in a Classic settings page; verify current options and organizational requirements before changing them.
