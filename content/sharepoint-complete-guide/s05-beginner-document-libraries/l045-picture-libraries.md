## 中文短总结

Picture Library 面向图片管理，默认字段和缩略图视图更适合浏览图像，并支持版本历史和 Check in / Check out。虽然可能接受其他文件，但非图片内容通常更适合通用文档库。

## 中文长总结

### 图片优化

- Picture Library 的默认 metadata 与图片相关，例如图片尺寸和文件大小。
- 缩略图视图便于浏览图片，也可切换到列表或紧凑列表。
- 相较于通用文档库，专用图片库可针对图片显示和浏览进行优化。

### 管理能力与适用范围

- 可上传图片并使用版本历史、Check in / Check out 等库功能。
- 其他类型文件可能也能存入，但不会有相应的图片属性，且不属于该库的主要用途。
- 可将图片库添加到站点导航，方便用户访问。

## English Short Summary

A Picture Library is designed for image management, with image-related metadata and a thumbnail-oriented default view. It also supports library features such as version history and check-in/check-out. Other files may work but are generally better suited to a general document library.
