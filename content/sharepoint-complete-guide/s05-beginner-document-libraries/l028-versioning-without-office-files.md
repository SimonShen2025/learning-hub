## 中文短总结

非 Office 文件也可通过同名文件替换来保留版本历史，并可查看或下载旧版本。与支持协同编辑的 Office 文件不同，其他文件通常不能多人同时编辑，但仍能利用版本记录进行追踪和恢复。

## 中文长总结

### 更新非 Office 文件

- 上传更新版时保持文件名相同，SharePoint 会提示将其作为现有文件的新版本替换，而不是创建一个独立的“第二版”文件。
- 版本历史会记录不同版本；可打开或下载旧版本以查看、恢复所需内容。
- Check out / Check in 也可用于文件编辑控制与记录变更说明。

### 与 Office 文件的区别

- 非 Office 文件通常不支持像 Word、Excel、PowerPoint 那样的多人同时协同编辑。
- 版本历史、替换版本和 Check in / Check out 等管理能力仍可帮助维护其他文件类型的修改记录。

## English Short Summary

For a non-Office file, upload an updated file with the same name and replace the existing one to create a new version. Version history can be used to inspect or download earlier versions. Co-authoring may not be available, but version tracking and check-in/check-out can still help manage changes.
