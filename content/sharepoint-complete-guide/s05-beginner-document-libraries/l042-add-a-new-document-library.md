## 中文短总结

当不同文件类别需要不同 metadata 时，可为费用、报价等用途创建独立文档库，而不是把所有内容塞入同一库。可从 Site contents 添加新的 Document Library，再按其用途配置列、视图和文件。

## 中文长总结

### 为什么拆分文档库

- 不同内容需要不同属性：费用文件可能需要部门、费用类型和金额；报价可能需要客户、报价金额和工作类别。
- 将各类文件放入独立文档库，可让每个库使用相关的 metadata、视图和管理设置，避免无关字段混杂。

### 创建入口

- 从 **Site contents** 查看站点中的应用，并选择 **New > App** 添加 Document Library。
- 也可使用站点提供的快速创建入口；通过 Site contents 可再次找到新库。
- 创建后可上传对应文件并设置适用的 metadata 和视图。

选择文档库边界时，应基于文件类型、分类方式和管理需求，而非只按文件数量决定。

## English Short Summary

Create separate document libraries for content types that need different metadata—for example, expenses versus quotes. Add a Document Library through Site contents, then configure its relevant columns, views, and files.
