## 中文短总结

有了 metadata 列，用户可按部门或费用类型筛选文件，也可按列分组查看各类别。不同成员可基于同一文档库选择自己的筛选和分组方式，不必将文件复制到多个目录。

## 中文长总结

### 筛选

- 按部门筛选，只显示选定部门对应的文件；也可清除筛选恢复全部内容。
- 按费用类型筛选可跨部门查找相同类别的文件，不需要逐个打开部门文件夹。
- 可组合多个筛选条件，缩小到需要处理的项目。

### 分组

- 按部门或费用类型分组，可在同一文档库中查看各类别的文件集合。
- 分组和筛选依据 metadata 列；用户可按自身职责选择不同分类视图。

Metadata 让同一文件集可以按多种业务维度查看，减少为每种分类方式重复维护目录的需要。

## English Short Summary

Metadata columns let users filter a library by department or expense type and group files by those values. Different users can view the same files through their own filters and groupings without duplicating them into multiple folder structures.
