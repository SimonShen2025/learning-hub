## 中文短总结

视图格式可根据 metadata 条件突出整行或单元格，也可用 Data Bars 显示数值相对大小。条件格式支持的列类型可能有限；课程演示中 Currency 列不可用，实际操作应先确认当前支持情况。

## 中文长总结

### 条件格式

- **Format current view** 可按条件设置行的背景色，例如将超过某金额的费用标红。
- 可添加多条规则，也可只格式化某一列，而不是整行。
- 在课程演示的 SharePoint 界面中，Currency 列未出现在条件格式规则可选项里；讲师将其改成 Number 并设置货币符号后继续演示。列类型支持可能随产品更新而变化，操作前应检查当前界面和文档。

### Data Bars 与选择项样式

- 数值列可使用 **Data Bars** 表示相对大小。
- Choice 列可使用颜色或 Choice pills 等样式。
- Data Bars 依赖当前可见数据的相对范围；异常值可能让其他值的差异不明显。

## English Short Summary

View formatting can highlight rows or individual cells based on metadata conditions, and Data Bars can show relative numeric values. Supported column types may vary; the course demo could not use a Currency column in conditional rules, so verify current support before changing a column.
