## 中文短总结

Check out 可暂时阻止其他人编辑文件；完成修改后执行 Check in，使文件恢复可共同编辑，并可附上变更说明。该流程也适用于非 Office 文件，适合需要控制编辑和记录变更理由的场景。

## 中文长总结

### 操作流程

1. 对文件执行 **Check out**，SharePoint 会标记文件正在由当前用户编辑，其他人仍可查看但不能编辑。
2. 完成修改后执行 **Check in**，让文件重新可供其他人编辑。
3. Check in 时可添加变更说明；说明会与版本历史一起保留。

### 使用场景

当编辑期间不希望他人同时修改文件，或需要记录谁在何时、因何原因更新文件时，可使用此流程。它可用于不同类型的文件，适合强调审核轨迹的文档管理场景。

## English Short Summary

Check out a file to prevent others from editing it while you work. After making changes, check it in so others can edit again, optionally adding a change comment to the version history. This can support controlled editing and audit trails for different file types.
