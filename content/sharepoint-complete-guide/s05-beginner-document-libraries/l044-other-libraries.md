## 中文短总结

除通用 Document Library 外，SharePoint 还提供面向特定内容的库类型，例如 Form Library、Wiki Page Library 和 Picture Library。Picture Library 适合按图片内容管理资源；选择专用类型前应确认它符合当前站点的功能需求。

## 中文长总结

### 可选库类型

课程演示从 Site contents 的应用目录查看内置库类型，包括：

- **Form Library**：管理表单相关文件。
- **Wiki Page Library**：管理 Wiki 页面。
- **Picture Library**：专用于图片资源。

### 选择合适类型

通用 Document Library 可存储多种文件；专用库则针对特定内容提供相应的创建方式和默认设置。讲师以创建 Picture Library 作为示例。实际选择时，应结合当前 SharePoint 环境中可用的功能及内容管理需求。

## English Short Summary

Besides general document libraries, SharePoint offers specialized library types such as Form Library, Wiki Page Library, and Picture Library. Choose a specialized type when its content and defaults fit the use case, and verify availability in the current environment.
