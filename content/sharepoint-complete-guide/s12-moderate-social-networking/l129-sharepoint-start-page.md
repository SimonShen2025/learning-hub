## 中文短总结

SharePoint Start page 汇集用户关注或常访问的站点、近期新闻和部分站点活动，帮助快速返回内容。显示项目及其可访问性取决于用户权限、关注关系和租户配置。

## 中文长总结

### Start page 内容

- 从 Start page 查看可访问站点的近期新闻和活动。
- 常访问或关注的站点可作为快速入口，减少逐层查找。
- 选择新闻或站点链接可进入相应页面。

### 个性化与权限

Start page 是个性化的浏览入口，不会改变底层站点的权限。新闻和站点是否显示，取决于用户可访问的内容、站点活动及当前 SharePoint 配置。

## English Short Summary

The SharePoint Start page can bring together recent news, activity, followed or frequently visited sites, and quick links. What appears depends on the user's access, followed sites, and tenant configuration.
