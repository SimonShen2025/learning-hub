## 中文短总结

课程区分本地部署的 SharePoint Server Standard / Enterprise 与云端 SharePoint Online，并聚焦持续更新的 SharePoint Online。讲师也提到 SharePoint Designer 2013 已久未更新，课程改用集成工作流和 Power Automate 讲解自动化。

## 中文长总结

### SharePoint Server

- SharePoint Server Standard 和 Enterprise 属于本地部署（on-premises）选项，组织在自己的服务器上托管数据。
- 课程将 Enterprise 描述为提供更高级的搜索、社交和权限功能；Standard 则覆盖站点、列表、文档库、页面及权限等基础能力。

### SharePoint Online

- SharePoint Online 由 Microsoft 托管，通过 Web 使用，并持续更新。
- 本课程主要学习 SharePoint Online，讲师将其作为课程中相关站点、内容和协作功能的重点平台。
- 部署选择应结合组织对数据托管方式的要求；本地部署和云端部署的责任与环境不同。

### 工作流工具

- 讲师指出 SharePoint Designer 2013 已长期未更新，因此课程将用集成工作流和 Power Automate 介绍工作流场景。

## English Short Summary

The lecture contrasts on-premises SharePoint Server Standard and Enterprise with Microsoft-hosted SharePoint Online, which is the course focus. It also notes that SharePoint Designer 2013 is outdated and introduces integrated workflows and Power Automate instead.
