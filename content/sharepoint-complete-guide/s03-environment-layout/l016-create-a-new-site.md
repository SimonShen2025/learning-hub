## 中文短总结

在 SharePoint 中创建站点时，选择 Team site 或 Communication site，再设置名称、地址、描述、语言和访问范围。Private 站点仅允许受邀成员访问；Public 站点面向组织成员开放，并不代表互联网公开。

## 中文长总结

### 创建流程

1. 从 Microsoft 365 或 SharePoint 首页进入 **Create site**。
2. 选择 **Team site** 或 **Communication site**。本课程为了后续协作练习选择 Team site。
3. 设置站点名称、地址和描述，并选择站点语言。
4. 选择访问范围，再添加站点所有者或成员；成员也可在创建后添加。

### 访问范围

- **Private**：只有已获邀请的组织成员可以访问。
- **Public**：组织中的成员均可访问；它不是对互联网开放的匿名公共网站。

创建站点前应根据协作需求和访问控制要求选择站点类型与可见范围。

## English Short Summary

Create a SharePoint site by choosing Team site or Communication site, setting its name, address, description, and language, then selecting its access scope. A private site is limited to invited members; public means organization-wide access, not public internet access.
