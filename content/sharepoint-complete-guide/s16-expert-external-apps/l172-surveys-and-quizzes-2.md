## 中文短总结

Microsoft Forms 可创建包含选择题和评分题的问卷，预览桌面或移动体验，并通过链接或 SharePoint Forms Web Part 收集响应。分享时应限制可响应对象并确认数据处理设置。

## 中文长总结

### 创建与分享

- 在 Microsoft Forms 中建立表单并添加选择题、评分题等问题。
- 预览桌面及移动布局，并按需调整主题和必答设置。
- 可复制表单链接，也可将 Forms Web Part 加入 SharePoint 页面并嵌入现有表单。

### 响应范围

分享设置可限制响应者，例如仅允许组织内用户。发布前确认目标受众、响应可见性和数据处理要求，避免将内部表单意外开放给外部人员。

## English Short Summary

Create a Microsoft Form with choice or rating questions, preview it on desktop and mobile, and share it by link or embed it with a SharePoint Forms Web Part. Set the intended response audience before publishing.
