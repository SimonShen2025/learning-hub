## 中文短总结

Countdown Web Part 可展示到指定日期和时间的倒计时，并配置标题、背景图、显示单位及 Call to Action 链接。其他 Web Parts 通常也可通过属性面板编辑，具体选项依组件而异。

## 中文长总结

### 配置倒计时

- 在 Site Page 添加 **Countdown** Web Part，设置目标日期和时间。
- 配置标题、背景图片以及倒计时显示内容，如天、小时、分钟或秒。
- 可添加 Call to Action 文案和链接，引导用户前往活动详情或相关页面。

### 其他 Web Parts

课程也提醒，页面组件各有属性面板，可按需调整其显示与内容。无需逐一学习所有组件；先选择符合页面目标的组件，再检查当前提供的配置选项。

## English Short Summary

The Countdown web part displays time remaining until a chosen date and time. Configure its title, background, displayed time units, and optional call-to-action link; other web parts have their own property options.
