## 中文短总结

Site Page 可通过分栏布局嵌入图片库等 Web Parts，并调整标题背景图、焦点和组件设置。页面因此能同时提供说明内容和图片资源入口；用户能执行哪些操作取决于库权限。

## 中文长总结

### 添加内容区域

- 编辑 Site Page，设置标题背景图片并调整图片焦点。
- 添加新分栏区域，例如三分之一与三分之二布局。
- 在区域中插入 Picture Library Web Part，并选择站点中的图片库。

### 配置组件

可设置组件显示大小、是否显示命令栏等选项，再保存并重新发布页面。具备相应权限的用户可从页面查看或使用图片库内容；嵌入组件本身不会改变底层权限。

## English Short Summary

Add a Picture Library web part to a Site Page section, and configure its size and command bar. The page can combine explanatory content with image resources; available actions still depend on the library's permissions.
