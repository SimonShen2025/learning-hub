## 中文短总结

Site Page 可添加 Call to Action 和 Button Web Parts，设置按钮文字、背景图和目标链接，引导用户前往相关页面或资源。发布前应测试链接，并按需要为页面配置适当权限。

## 中文长总结

### 页面内导航

- 使用 **Call to Action** Web Part 添加说明文字、背景图片和按钮链接，例如将用户引导至相关费用页面。
- 使用 **Button** Web Part 设置按钮标签及目标地址，例如返回站点主页。
- 也可在图片或文本中加入链接，提供其他导航方式。

### 使用建议

页面内导航可连接站点中的不同页面或外部资源。应确保标签清晰、链接目标正确，并在发布后验证访问路径；链接本身不会改变目标页面的权限。

## English Short Summary

Add Call to Action and Button web parts to a Site Page, setting labels, background images, and target links to guide users to related pages or resources. Test links after publishing; navigation links do not change destination permissions.
