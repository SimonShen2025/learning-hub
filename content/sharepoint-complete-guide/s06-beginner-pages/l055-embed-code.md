## 中文短总结

Wiki page 可通过 Embed Code 插入外部内容，例如视频播放器的 iframe 代码，并调整嵌入区域尺寸。可嵌入内容和代码受 SharePoint 安全设置及组织策略限制，应使用可信来源。

## 中文长总结

### 添加嵌入内容

- 编辑页面并选择 **Insert > Embed Code**，粘贴外部服务提供的嵌入代码。
- 可调整嵌入区域宽度和高度，再保存页面检查呈现效果。
- 课程以视频作为示例；其他服务是否可嵌入取决于其提供方式及 SharePoint 环境。

### 安全与兼容性

嵌入代码可能加载外部内容，且不同脚本或域名的支持情况不同。使用可信来源，并遵循组织的 SharePoint 嵌入和安全策略；若内容被阻止，应检查租户设置与服务支持，而不是绕过限制。

## English Short Summary

Use Insert > Embed Code to add externally hosted content, such as a video iframe, and adjust its dimensions. Supported code and domains depend on SharePoint security settings and organizational policy; use trusted sources.
