## 中文短总结

Hero Web Part 可用图片和链接突出最多五项重点内容，支持 Tiles 或 Layers 布局。可调整图片裁切和焦点，并为每个项目配置标题及 Call to Action 链接。

## 中文长总结

### Hero 布局

- 在 Site Page 添加 **Hero** Web Part，以较大的图片区域展示重点内容。
- 可选择 Tiles 或 Layers 等布局，并配置可展示的项目数量（课程演示最多五项）。

### 配置项目

- 为每个项目设置图片、标题和显示焦点，必要时调整图片缩放与裁切。
- 可配置 **Call to Action** 文案和目标链接，指向外部网站或站点内相关页面。

Hero 适合突出重点入口；应确保图片、链接和按钮文案与目标内容一致。

## English Short Summary

The Hero web part presents key content through linked image tiles or layers, with up to five items in the course demo. Configure each item's image crop, focal point, title, and call-to-action link to an internal or external destination.
