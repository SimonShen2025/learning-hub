## 中文短总结

SharePoint 主页由多个 Web Parts 组合而成。课程示例新建 Site Page，加入新闻轮播、群组日历、费用与产品入口及站点活动，发布后将页面设为主页。

## 中文长总结

### 主页结构

现有主页包含 News、Activity、Documents 和 Quick Links 等 Web Parts。选择组件后可配置其数据来源、展示方式和排序。

### 构建自定义主页

- 新建 Site Page 并设置标题区域和图片。
- 添加 News Web Part（示例使用 Carousel）、Group Calendar、Call to Action 和 Site Activity 等组件。
- 将 Call to Action 链接到常用页面，例如费用提交入口或产品信息页。
- 发布页面后，从 Pages 菜单将其设为站点主页。

主页应优先呈现用户高频使用的信息和入口；组件中的数据仍受对应应用和访问权限控制。

## English Short Summary

A SharePoint home page is a composition of web parts. The example creates a Site Page with a news carousel, group calendar, calls to action for common pages, and site activity, then publishes it and sets it as the site's home page.
