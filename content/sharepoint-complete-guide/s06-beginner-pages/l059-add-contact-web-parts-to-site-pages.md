## 中文短总结

People Web Part 可在 Site Page 展示组织成员及其说明，帮助访问者找到联系人。根据用户的 Microsoft 365 配置，访问者可从人员卡片进入个人资料或发起邮件、聊天等操作。

## 中文长总结

### 添加联系人

- 在 Site Page 添加 **People** Web Part，并选择组织中的一个或多个成员。
- 可为联系人填写职责或说明，帮助访问者了解应联系谁。
- 重新发布后，人员卡片会显示在页面上。

### 页面交互

选择人员卡片可打开个人资料，并可能提供邮件、聊天或 Teams 等联系入口；具体操作取决于组织的应用配置和访问权限。

## English Short Summary

Add a People web part to a Site Page, select organization members, and provide role descriptions so visitors know whom to contact. Depending on Microsoft 365 configuration and permissions, people cards can link to profiles, email, chat, or Teams.
