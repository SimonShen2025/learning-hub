## 中文短总结

基础块包括文本格式、标题、待办/项目列表、表格、toggle、quote、divider、callout 和页面链接。通过 slash command 插入，再按内容层级组合块。

## 中文长总结

- 文本可添加链接、粗体、斜体、下划线、删除线、代码样式及颜色；Heading 1–3 建立视觉层级。
- Bulleted/numbered list 支持缩进，to-do list 可勾选完成。简单表格可添加行列及表头。
- Toggle 用于折叠内容，quote 与 callout 用于强调信息，divider 分隔区块；link to page 可连接工作区内的其他页面。
- 使用 slash command 快速插入块，并根据页面用途组织结构，避免堆叠过多无关元素。

## English Short Summary

Basic blocks include formatted text, headings, lists, to-do items, tables, toggles, quotes, dividers, callouts, and page links. Insert them with slash commands and combine them into a clear page hierarchy.
