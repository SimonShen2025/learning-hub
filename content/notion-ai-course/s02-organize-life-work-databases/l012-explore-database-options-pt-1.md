## 中文短总结

Property 菜单可改名、改类型、配置 Select 选项、隐藏、冻结、复制或删除字段。Select 的选项顺序会影响排序结果；view 设置则控制布局、显示属性和页面打开方式。

## 中文长总结

- Property 菜单可调整标题和图标、修改 property type、维护 Select/Multi-select 选项，也可隐藏、复制或删除字段。
- Select 选项的自定义顺序可能决定按该属性排序时的顺序；若结果不符合预期，先检查选项列表顺序。
- 可冻结左侧列、启用/关闭单元格换行，并分别配置不同 view 显示哪些 properties 及显示顺序。
- View 的 Layout 菜单可切换 table/board/calendar 等布局、调整数据库外观和页面打开方式（side peek、center peek、full page）。

## English Short Summary

Property menus manage field names, types, select options, visibility, order, freezing, duplication, and deletion. Select-option order can affect sorting. View layouts independently control displayed properties and page-opening behavior.
