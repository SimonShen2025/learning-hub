## 中文短总结

五个最常用的 Slack 动作：1）创建 channel（public 或 private），并写好 description；2）把关键消息 pin 到 channel 顶部的 Pins 标签；3）用顶部 search 跨 channel 搜消息、文件、链接和用户；4）用 `/remind` 设置只有自己能看到的提醒；5）用 emoji reaction 代替“收到/同意”之类的短回复，减少无效消息。

## 中文长总结

### 注册与界面

- Slack 免费，在 slack.com 用 Google、Apple 或任意邮箱注册；公司环境先确认公司是否已有 license，再用工作邮箱登录
- 右侧是消息窗口；左侧是 **Channels**（按主题、团队或项目划分的群聊）和 **Direct messages**（与个人或小群的非主题聊天）

### 1. 创建 channel

- Channels → Add Channels → Create，可选模板或 Blank Channel
- Channel 名以 `#` 开头，全小写
- **Public**：workspace 内任何人可发现并加入；**Private**：仅邀请成员可见（如筹备惊喜派对）
- 可邀请成员，或先跳过
- 点击 channel 名称可编辑名称、topic、description；人一多就会加入很多 channel，所以 description 很重要
- 邀请他人前先发一条介绍消息（目的、议程、关键链接）

### 2. Pin 消息

- 消息右侧三个点 → Pin to channel
- 顶部出现 **Pins** 标签，集中存放关键消息、资源、链接，避免成员上下翻找

### 3. Search

- 顶部搜索栏可搜内容、消息、链接、附件、用户
- 可限定当前 channel，也可跨所有 channel 搜索

### 4. Reminder

- 输入 `/remind call Mark in 30 minutes`
- Slackbot 的回复只对自己可见，可在任何 channel 或 DM 中使用

### 5. Emoji reaction

- 用 ✅、👀 等 emoji 回应消息，代替“收到，我同意”之类的完整回复
- 发送者悬停即可看到谁用什么 emoji 回应

## English Short Summary

Five time-saving Slack moves: create a channel (public vs private) and add a description; pin key messages to the channel's Pins tab; use the global search across messages, files, links and people; set private reminders with `/remind`; and reply with emoji reactions instead of short "OK" messages.
