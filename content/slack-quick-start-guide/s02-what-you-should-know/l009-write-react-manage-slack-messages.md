## 中文短总结

Shift+Enter 换行，Enter 发送（可在 Preferences → Advanced 改成 Ctrl+Enter 发送）。DM 适合临时或随意的对话，channel 适合固定主题。自己的消息可编辑（会标记 edited）或删除。处理收到的消息：emoji reaction、reply in thread（不打乱主线）、forward、save for later、add to list（变成 to-do）、mark unread、remind me、pin。需要对方尽快回复时用 @mention。

## 中文长总结

### 写消息

- **Shift+Enter** 换行，**Enter** 发送
- Preferences → Advanced → Start a new line：改成 Enter 换行、**Ctrl+Enter** 发送
- 格式工具：bold、italic、strikethrough、link、列表、block quote、code、code block
- 附件：file、workflow、text snippet、canvas
- Emoji 搜索、@mention、video clip、audio clip、schedule send

### DM 与 channel

- 左上角 + → New message，可发给 channel、个人或多人；也可通过 **Slack Connect** 发给组织外的人（后面讲）
- **Channel**：固定主题，有更多结构化能力（tabs、workflows）
- **DM**：随意聊天，或多人临时讨论某个话题
- 两者的消息功能基本相同

### 管理自己的消息

- 三个点 → **Edit message**：保存后标记为 edited（防止悄悄修改审批类内容）
- 三个点 → **Delete message**

### 处理收到的消息

- **Emoji reaction**：右上角默认 3 个常用 emoji（可自定义），如 ✅ 表示完成或同意、👀 表示在看，不用写完整回复
- **Reply in thread**：针对某条旧消息开子对话，不打乱主对话；可勾选同时发到 channel 或 DM；可以开多个 thread
- **Forward**：转发到其他 channel 或个人，可附加说明
- **Save for later**：书签，在左侧 Later 中查看，可标记完成、设提醒或移除
- **Add to list**：把消息加入 list（如新建 todo list），变成任务
- **Turn off notifications for replies**：只关掉这条 thread 的通知
- **Mark unread**：标为未读
- **Remind me**：按分钟、小时、天、周或自定义时间提醒
- **Pin**：放进顶部 Pins 标签，避免重复发送常被问到的资源

### Pro tip

- 需要对方尽快回复时用 `@username`，消息会直接进对方的通知

## English Short Summary

Shift+Enter adds a new line, Enter sends (switchable to Ctrl+Enter in Advanced preferences). Use DMs for ad-hoc chats and channels for fixed topics. Edit (marked as edited) or delete your messages. Handle incoming messages with emoji reactions, threads, forward, save for later, add to list, mark unread, remind me and pin. @mention someone when you need a fast reply.
