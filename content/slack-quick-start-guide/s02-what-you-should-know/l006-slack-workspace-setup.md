## 中文短总结

Workspace 是一个完全封闭的沟通空间，信息不能在 workspace 之间共享。绝大多数情况下整个公司用一个 workspace，只有需要隔离某些团队时才建多个。流程：在 slack.com 用工作邮箱、Google 或 Apple 注册，创建 workspace，填写名称和个人资料，邀请成员，创建第一个 channel，选择 Free 或 Pro。左上角可添加或切换 workspace。小技巧：抢先建好 workspace 再邀请团队，规则和通知设置由你来定。

## 中文长总结

### Workspace 的规模怎么定

- Workspace 好比办公楼，所有团队、channel、附件都在里面
- 两种方式：每个团队一个 workspace，或整个公司一个 workspace
- Workspace 是 **fully enclosed** 的，设计上不在 workspace 之间传递信息
- 只有需要把某些部门或团队隔离开（不能或不该互相沟通）时才建多个；**99% 的情况一个公司一个 workspace**

### 创建账号

- slack.com → Create an account
- 三种方式：工作邮箱（公司已用 Slack 时可能直接加入公司 workspace）、Google、Apple

### 创建 workspace

1. Create a workspace，输入名称（团队名或公司名）
2. 设置个人资料：名字、头像（建议上传照片，更有人情味）
3. 邀请成员：输入邮箱（逗号分隔）、导入 Google Contacts、或分享邀请链接，也可跳过
4. 创建第一批 channel：填写团队当前在做的项目
5. 选择套餐：个人或朋友使用免费版通常够用；公司一般已有 Pro license；如果由你在公司推行 Slack，可以联系销售谈定制价格

### 多个 workspace

- 左上角 → Add a workspace：加入别人分享的、登录已有的，或新建一个
- 同样在左上角切换；不同 workspace 完全隔离，信息不能互通

### Pro tip

- 在团队之前先建好 workspace 并邀请他们，规则、设置和通知都由你来定，你也会被看作 Slack 专家

## English Short Summary

A workspace is a fully enclosed communication space, and information can't flow between workspaces, so most companies use one workspace and only split it when teams must be separated. Walkthrough: sign up (work email, Google or Apple), create a workspace, set your profile, invite members, create first channels, pick Free or Pro, and add or switch workspaces from the top-left menu.
