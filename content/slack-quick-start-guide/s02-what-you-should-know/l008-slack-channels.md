## 中文短总结

Channel 像贴了标签的会议室，按主题、团队或项目划分，private channel 用于 HR 等敏感话题。创建时可选模板或 blank channel，名称全小写。**Public 可以转成 private，private 永远不能转回 public**。消息框支持格式、附件、mention、录音录像和定时发送。设置面板可编辑 topic、description、成员，可 archive（保留内容）或 delete（永久删除）。可 star channel 并用 sections 分组。讲师提供了 description 模板：purpose、who should join、key resources。

## 中文长总结

### 什么是 channel

- 像贴了标签的会议室，标签说明里面讨论什么：特定主题（如申请 IT 设备）、团队任务、项目（如公司派对），或仅邀请可见的 private channel（如 HR 事务）
- 常见问题：所有内容都丢进 general 或 random，最后什么都找不到；应该有策略地规划 channel

### 创建 channel

- 加入公司 workspace 时通常会被自动加入一些核心 channel；新账号则是空的
- Channels → Create → Create Channel；左侧有模板（如 Project Starter Kit 自带 project overview、tracker、workflows），这里先选 **Blank channel**
- 名称强制小写，空格自动变成 `-`

### Public 与 private

- **Public**：workspace 内任何人可查看并自行加入，适合通用讨论和流程
- **Private**：仅邀请，适合保密项目、成员稳定的项目、HR 话题
- **关键限制**：public → private 可以；**private → public 不行**，因为要保护私密对话不被公开
- 所以创建前就要想好主题和成员

### 消息框功能

- 格式：bold、italic、link、有序或无序列表、block quote、inline code、code block
- 附件：workflow、canvas、list 等（后面讲）
- Emoji、@mention（对方会收到通知）、video clip、audio clip（类似 WhatsApp 语音）、shortcuts
- **Schedule send**：定时发送（如周一 9 点，或两天后的生日祝福）

### Channel 设置

- 右上角添加成员或整个团队
- **About**：改名、topic、description；查看 channel manager、创建者和创建时间；离开 channel（manager 离开会失去管理权）
- **Files**：channel 内所有文件
- **Settings**：**Archive**（关闭但保留消息）、**Delete**（永久删除全部内容）、转为 private
- 顶部：开 **huddle**（channel 成员通话）、通知级别（只有 mention、全部或关闭）

### Star 与 sections

- **Star** 常用 channel，加入很多 channel 时很有用
- **Sections**：像文件夹一样组织 channel，可设 emoji，拖拽移动 channel；删除 section 后其中的 channel 回到默认 Channels 区

### Description 模板（Pro tip）

- **Purpose**：channel 的简短目的
- **Who should join**：谁应该参与
- **Key resources**：关键资源位置，或沟通机制（如每周 sync）
- 模板作为本节资源提供

## English Short Summary

Channels are labeled meeting rooms for topics, teams or projects. Create from a template or blank; names are lowercase. Public can become private, but private can never become public. Messages support formatting, attachments, mentions, audio and video clips, and scheduled sends. Settings cover topic, description, members, archive vs delete. Star channels, group them into sections, and use the purpose / who-should-join / key-resources description template.
