## 中文短总结

每个 channel 和 DM 都有 tabs：Messages（默认）、Canvas（类似 Notion 的 channel wiki，有模板，可插入表格、分栏、清单、文件、profile 和日期等）、List（可加字段的任务清单，支持 Kanban 视图、筛选、排序、分组）、Bookmarks（常用链接）、Pins、Files（有文件才出现）。可拖拽调整顺序、隐藏 tab，建议只让 channel manager 修改 tab。没用模板也能之后补加。Pro tip：重要更新放进 tab 而不是消息流。

## 中文长总结

### Channel tabs 概览

- 每个 channel 和 DM 都有内置 tabs，用来整理重要消息、文件、书签和 workflows
- 点右侧 + 添加 tab；Edit tabs 可显示或隐藏 tab
- 权限设置：谁可以 add、remove、reorder tabs，**建议设为 channel managers only**

### Canvas

- 放静态信息的页面，相当于 team wiki 或 channel wiki：project charter、链接、资源、项目描述、重要截止日期
- 可以从空白开始，也可以 **Explore templates**（to-do list、agenda、employee onboarding 等），模板自带占位内容
- 可搜索已有或别人分享的 canvas 复用
- 有标题和 cover image（类似 Notion）
- 格式：heading（small、medium）、checklist、block quote、code block，与消息相同的格式工具
- 额外元素：**table**、**layouts**（2 或 3 栏）、file、video clip（如 CEO 欢迎视频）、audio clip、divider
- **Placeholder**：如 profile placeholder，标注“project manager”后再指定具体人；也可直接插入 profile、date
- 还可以插入 canvas（嵌套）、image、link、workflow
- 右键元素 → Remove

### List

- 可新建或使用已有 list，如 to-do 或 project milestones
- 每个 item 可展开添加详情；**Add field** 支持 number、select 或 multi-select、date、people、phone、channel、vote，以及 created time、last edited 等 metadata
- 例：Status 字段（select：To do、In progress、Done，默认 To do）
- 视图：table 或 **board（Kanban）**；支持 filter、sort、hide fields、group by status
- 可以直接搭成项目 tracker

### Bookmarks、Pins 与 Files

- **Bookmarks**：添加常用链接，可编辑或删除
- **Pins**：消息三个点 → Pin to channel 后自动出现，可 unpin 或删除
- **Files**：channel 里有文件时才出现；可搜索、star、forward、delete

### 其他

- 拖拽 tab 调整顺序
- 没用模板创建也没关系：+ → **Add template to channel** 随时补加
- Workflow tab 留到后面单独讲

### Pro tip

- 重要通知用 `@channel` 提醒全员，同时把关键更新放进 tab（canvas 或 pins），而不是埋在 thread 里；大多数人会先看 pinned 信息，而不是翻 200 多条未读消息

## English Short Summary

Every channel and DM has tabs: Messages, Canvas (a Notion-like channel wiki with templates, tables, layouts, checklists, files and profile/date placeholders), List (custom-field task tracker with Kanban board, filter, sort, group), Bookmarks, Pins and Files. Reorder or hide tabs, restrict tab edits to channel managers, and add a template later if needed. Keep key updates in tabs rather than message threads.
