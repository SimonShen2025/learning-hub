## 中文短总结

**Huddles**：在 channel 或 DM 一键开语音或视频通话，不需要会议链接；支持静音、摄像头、屏幕共享、reaction、邀请、复制 huddle 链接、设置 topic、全屏、thread 和 notes，以及独自等待时播放音乐。**Slack Connect**：通过 More → External connections 创建与外部人员共享的 channel 或 DM，用邮箱邀请；外部人员（邮箱域名不同）无需购买 license。Admin 可管理邀请、审批和 active connections。可用 `/huddle` 快速开会。

## 中文长总结

### Huddles（内部通话）

- 即时、低压力的语音或视频通话，无需会议链接或下载
- 在 channel 或 DM 右上角点耳机图标即可开始
- 控制项：mute、camera、**screen share**、reactions、邀请他人
- 更多选项：复制 huddle 链接（通过 DM 分享）、设置 topic（如 weekly sync）
- **全屏模式**：完整控制面板、thread、**notes**
- 独自在 huddle 时可播放音乐（可设入会时、独处时、30 秒或 1 分钟后，或从不）
- 在 DM 中开 huddle，对方会收到邀请；聊天中会显示 huddle 进行中
- 点 Leave 结束

### Slack Connect（外部沟通）

- 让供应商、客户等外部伙伴加入 Slack 对话，避免又回到邮件或 Zoom 链接
- **外部人员不需要付费 license**；前提是对方邮箱域名与你公司不同，否则会被算作内部付费用户
- Channel 会标明是 Slack Connect channel，提示有外部人员在场
- **创建 channel**：More → External connections → 创建 channel，命名（如 procurement-team）并设置可见性 → 右上角 Add people → 输入对方邮箱发邀请
- **创建 DM**：More → External connections → Start a DM → 输入邮箱

### 管理 connections（需要 admin）

- External connections 页面底部 → Manage connections
- **Slack Connect channels**：邀请类型（仅发帖，或可邀请其他人）、本组织成员能否加入外部 channel、谁可以审批 Slack Connect 请求
- **Manage requests**：查看待接受的邀请和请求，可撤销发错的邀请
- **Managed connections**：查看当前 active connections

### Tips

- 说服犹豫的合作伙伴：可以继续用邮件，但 Slack 回复速度快三倍
- 在任意 channel 或 DM 输入 `/huddle` 立即开 huddle

## English Short Summary

Huddles are one-click voice and video calls in any channel or DM, with screen share, reactions, invite links, topics, full-screen notes and threads. Slack Connect creates shared channels or DMs with external partners invited by email; external users with a different email domain need no paid license. Admins manage invitations, approvals and active connections. Use `/huddle` to start one instantly.
