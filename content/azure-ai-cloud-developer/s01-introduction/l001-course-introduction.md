## 中文短总结

本课程面向 AI-200 Azure AI Cloud Developer Associate 认证考试，由 Kuljot Singh Bakshi 讲授。课程聚焦生产级云端架构模式而非单纯调用 AI 模型，涵盖容器化 AI 应用、数据检索系统（Cosmos DB、PostgreSQL、Redis、RAG）以及集成/安全/监控（Service Bus、Event Grid、Functions、Key Vault、App Configuration、OpenTelemetry）。

## 中文长总结

### 课程定位

- 面向 Microsoft AI-200（Azure AI Cloud Developer Associate）认证考试
- 讲师：Kuljot Singh Bakshi，技术数据与 AI 顾问，Udemy 头部讲师，同时运营 CarbonOps（AI 辅助 ESG 审计合规 SaaS）和 NIRL with Emsing（Azure/AI/云技术学习平台）
- 重点：不仅是学习单个 AI 服务调用方式，而是构建端到端、生产就绪的 AI 系统

### 三大学习路径（与官方 Study Guide 对齐）

1. **容器化 AI 解决方案**：Azure Container Registry、Azure Container Apps、App Service、Azure Kubernetes Service (AKS)
2. **AI 数据与检索系统**：Azure Cosmos DB、PostgreSQL、Azure Managed Redis、向量搜索、语义检索、RAG（检索增强生成）架构
3. **集成、安全与监控**：Azure Service Bus 与 Event Grid 事件驱动方案、Azure Functions 无服务器应用、Key Vault 与 App Configuration 安全配置、OpenTelemetry 与 KQL 监控分布式系统

### 课程特色

- 实操实验基于企业级架构模式（队列处理、事件驱动工作流、分布式应用、可扩展 AI 后端服务）
- 强调各 Azure 服务如何协同工作，而非孤立学习单个服务

## English Short Summary

Introduction to the AI-200 Azure AI Cloud Developer Associate certification course by instructor Kuljot Singh Bakshi. The course focuses on production-grade cloud architecture patterns rather than just calling AI models, covering three learning paths: containerized AI hosting, AI data/retrieval systems (Cosmos DB, PostgreSQL, Redis, RAG), and integration/security/monitoring (Service Bus, Event Grid, Functions, Key Vault, App Configuration, OpenTelemetry).
