## 中文短总结

本课概述课程结构：以理论讲解为辅、大量动手实验为主，与 AI-200 官方学习指南保持一致。建议学员先观看视频学习，再在自己的实验环境中重复操作，并善用 GitHub 仓库中的代码片段与说明。

## 中文长总结

### 课程结构

- 课程包含理论讲解，但绝大部分内容是动手实验（hands-on labs），这与 AI-200 考试大纲的要求高度一致
- 建议重点关注实操环节，并尽量在自己的实验环境中重复练习

### 学习建议

1. 跟随视频学习，吸收讲师的知识与实践经验
2. 有条件时在自己的环境中重复实验，以获得最佳学习效果
3. 实验所需的代码片段与操作说明均在讲师的公开 GitHub 仓库中，可 fork 或 clone
4. 配套的演示文稿会附在视频资源区，方便学员获取仓库链接
5. 保持享受学习过程的心态

### 收获

- 课程内容不仅有助于通过 AI-200 认证，也能提升实际工作中的技能

## English Short Summary

This lecture outlines the course structure — mostly hands-on labs aligned with the AI-200 exam guide, with lighter theory content — and gives learning recommendations: watch the videos first, then repeat labs in your own environment, and use the code snippets and instructions provided in the instructor's public GitHub repository. The course aims to build both exam-ready and real-world job skills.
