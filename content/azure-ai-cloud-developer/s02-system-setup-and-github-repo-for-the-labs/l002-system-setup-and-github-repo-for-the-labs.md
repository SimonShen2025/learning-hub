## 中文短总结

本课介绍了课程实操所需的 GitHub 仓库地址（讲师个人 GitHub 上的 "Azure AI Cloud Developer" 仓库）以及所需的系统环境：VS Code、Git Bash（或 PowerShell）、Azure CLI 和 Python。仓库 README 中提供了各软件安装链接。

## 中文长总结

### GitHub 仓库

- 仓库位于讲师的 GitHub 公开主页，名为 "Azure AI Cloud Developer"
- 需要 fork 或 clone 该仓库以获取实操所需的代码和脚本
- 仓库 README 中包含所需软件的安装链接

### 系统环境要求

- **VS Code**：作为本课程所有实验的集成开发环境（IDE）
- **Bash 终端**：用于执行命令脚本；若设备不支持 Bash，可使用 PowerShell 替代
  - 建议将 Bash 脚本粘贴给 ChatGPT 等 AI 工具，请求转换为 PowerShell 脚本
- **Azure CLI**：用于与 Azure 资源交互
- **Python**：课程中的代码示例均为 Python，因此为必需环境

### 学习建议

- 所有安装链接均已整理在仓库 README 中，避免自行搜索浪费时间
- 上述工具安装配置较为简单，多数学员设备可能已具备部分环境

## English Short Summary

This lecture points learners to the course's public GitHub repository ("Azure AI Cloud Developer") for all lab code and scripts, and lists the required local environment: VS Code as the IDE, a Bash terminal (or PowerShell as an alternative, with AI tools able to convert Bash scripts to PowerShell), Azure CLI, and Python. All installation links are provided in the repository's README file.
