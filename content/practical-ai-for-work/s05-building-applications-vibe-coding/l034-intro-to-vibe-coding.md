## 中文短总结

Vibe coding 是用自然语言描述要解决的问题和应用需求，由 AI 生成代码，再通过对话持续迭代。适合快速构建小型、明确的工作工具；从可运行的最小版本开始，并反复测试和修正。

## 中文长总结

Vibe coding 将与 AI 对话的方式用于创建软件：描述目标和期望行为，模型生成应用代码，随后通过反馈改进结果。它降低了原型开发门槛，可用于内部 dashboard、表单、报表、清单或行业专用计算器等具体问题。

关键是从真实痛点出发，不必一开始就构建大型产品。先明确用户、输入、输出和核心流程，生成最小可用版本，再实际测试并逐步迭代。错误和不符合预期的结果属于开发过程的一部分。

自然语言开发不等于无需工程判断。生成的应用仍可能有缺陷、安全和数据处理问题；涉及真实用户或业务数据时，应进行适当测试、审查和权限控制。

## English Short Summary

Vibe coding uses natural-language conversations to generate and refine software. Start with a focused workplace problem and a small working prototype, then test and iterate. Generated code still requires engineering review, especially for security and real data.
